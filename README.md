# Персональный сайт Людмилы Филатовой — ONELAF

Статический адаптивный сайт на HTML/CSS/JS, без сборщика, базы данных и сторонних скриптов аналитики. Он задуман как персональная презентация, которая направляет покупателей в существующий магазин ONELAF.

## Страницы
- `index.html` — главная, позиционирование, примеры публичных выступлений.
- `about.html` — о Людмиле и бренде.
- `expertise.html` — ONELAF, профессиональные роли и опубликованные темы выступлений.
- `contacts.html` — Instagram и публичные контакты ONELAF.
- `404.html` — страница для несуществующих адресов.
- `styles.css`, `script.js` — общий адаптивный дизайн и мобильная навигация.
- `assets/favicon.svg`, `assets/og-cover.png` — favicon и графика для социального превью.
- `robots.txt`, `.nojekyll` и `sitemap.xml.example` — файлы для статического хостинга и дальнейшей настройки поисковой индексации.

## Как опубликовать через GitHub Pages
1. Открой этот репозиторий: https://github.com/LordPandocha/Laf
2. Зайди в **Settings → Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**.
4. Выбери ветку `main` и папку `/ (root)), затем нажми **Save**.
5. После завершения публикации GitHub покажет публичный адрес сайта в разделе **Pages**.

## Подключение своего домена
1. В **Settings → Pages** введи домен в поле **Custom domain** и нажми **Save**.
2. У регистратора домена укажи DNS-записи, которые покажет GitHub Pages для корневого домена или поддомена.
3. Дождись проверки DNS и включи **Enforce HTTPS**, когда опция станет доступна.
4. После выбора домена нужно заменить шаблон `sitemap.xml.example` на реальный `sitemap.xml` и обновить абсолютные URL в SEO-разметке.

## Перед запуском
- Согласовать формулировки с Людмилой и право использования имени, бренда и публичных контактов.
- При необходимости заменить абстрактную иллюстрацию на утверждённые портреты.
- Проверить контакты на актуальность.

Форма обратной связи, корзина, оплата и сбор персональных данных не реализованы. Этот проект не заменяет и не изменяет магазин https://onelaf.ru/.
