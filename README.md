# Пироговая

Статический сайт для Пироговой в Новом Уренгое. Откройте `index.html` локально или разместите содержимое репозитория на GitHub Pages.

Меню, цены, контакты и фотографии собраны из [публичной карточки организации в Яндекс Картах](https://yandex.com/maps/org/pirogovaya/86559750538/). Цены на сайте сопровождаются пометкой о необходимости уточнения при заказе. Снимки показывают работы пекарни и не подписаны как фотографии конкретных товаров.

Сайт использует HTML, CSS и небольшой нативный JavaScript. Для сборки зависимости не нужны.
