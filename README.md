# Пироговая

Статический сайт для Пироговой в Новом Уренгое. Откройте `index.html` локально или разместите содержимое репозитория на GitHub Pages.

Каталог содержит 29 позиций из [публичного меню организации в Яндекс Картах](https://yandex.com/maps/org/pirogovaya/86559750538/menu/): опубликованные цены, отредактированные описания и фотографии соответствующих позиций. Актуальные цены и наличие посетителям предложено уточнять у пекарни. Остальные снимки сайта взяты из публичной галереи организации. Знак пирога в логотипе сгенерирован для этого сайта.

Сайт использует HTML, CSS и небольшой нативный JavaScript. Для сборки зависимости не нужны.
