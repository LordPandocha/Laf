# ONELAF

Статический адаптивный сайт бренда профессиональных материалов для маникюра. Дизайн: чёрный, графит, холодный хром и предметные фотографии ONELAF.

## Страницы

- `index.html` — главная, подборка материалов и переходы в официальный магазин.
- `expertise.html` — подход к продуктам и направления каталога.
- `about.html` — бренд и Людмила Филатова.
- `contact.html` — официальные каналы связи.
- `styles.css`, `script.js` — общие стили, мобильное меню и лёгкие анимации.

Без сборки и сторонних JS-библиотек. Для локального просмотра откройте `index.html` в браузере. Актуальные цены, наличие и инструкции находятся на `onelaf.ru`.

Фотографии в `assets/` взяты из официальных публикаций ONELAF; происхождение перечислено в `DESIGN_BRIEF.md`.
