# ONELAF — реализованное направление

Статус: пользователь подтвердил сайт товаров ONELAF, чёрно-хромовый стиль и поручил глобальный редизайн с публикацией.

## Решения

- Аудитория: мастера маникюра, выбирающие профессиональные материалы.
- Главный переход: подборка продуктов и официальный каталог `onelaf.ru`; цены и наличие остаются на сайте магазина.
- Визуальная система: графит `#101213`, почти чёрный `#090a0b`, холодный серебристый `#c5c9cc`, светлый `#ececeb`. Цвет продуктов остаётся в фотографиях.
- Страницы: главная с тремя отдельными сценами «Базы», «Гели», «Финиш» и товарами Base Soft / Gel Express Touch / Top Mirror; «Подход», «О бренде», «Контакты».
- Движение: при открытии продукта фотография занимает экран, стилизованно поворачивается, самолётик превращается в ленту и раскрывает проверенное описание. GSAP 3.13.0 лежит локально; без JavaScript прямые ссылки на каталог остаются доступными. Это стилизованное фото, а не физически точная 3D-модель.
- Устройства: адаптивная вёрстка от 320 px; клавиатурное меню; `prefers-reduced-motion`.
- Стек: HTML, CSS, нативный JavaScript и локальный GSAP для сценарной анимации.
